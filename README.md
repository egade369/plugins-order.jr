# Skript-scripts-order.sk , myorder.sk

A growing collection of custom Minecraft Skript systems and ongoing projects, featuring player-to-player trading, dynamic economies, and inventory management, with some scripts still under development and testing.

---

## Included Scripts

* `myorder.sk` - Premium custom order system with GUI menus, sorting, automated expiry, and delivery management.
* `chatorder.sk` - Interactive chat integration that converts `[order]` keywords into clickable buttons to inspect player orders.

---

## Requirements Plugin
 Skript
 Vault (Required for economy transactions)
